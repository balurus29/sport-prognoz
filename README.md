# СпортПрогноз — Android

Приложение загружает матчи и статистику из бесплатного открытого API ESPN и считает вероятности:
исход (П1/Х/П2), двойной шанс, тоталы, индивидуальные тоталы, форы, точный счёт,
«обе забьют», ценность ставки (по вашим коэффициентам) и текстовый разбор матча.

## Виды спорта (версия 1.0)

| Спорт | Турниры | Модель |
|---|---|---|
| Футбол | РПЛ, АПЛ, Ла Лига, Серия А, Бундеслига, Лига 1, Эредивизи, Португалия, Турция, ЛЧ, ЛЕ | Пуассон по голам |
| Хоккей | НХЛ | Пуассон по шайбам + овертайм |
| Баскетбол | НБА, NCAA | Нормальное распределение очков |
| Бейсбол | MLB | Нормальное распределение ранов |
| Теннис | ATP, WTA | Рейтинг/рекорд → вероятность сета → счёт по сетам |
| Волейбол | NCAA | То же, до 3 выигранных сетов |
| MMA | UFC, PFL | Рекорды бойцов (log5) |
| Киберспорт, наст. теннис | — | Нужен платный API (кнопки есть, отмечены «скоро») |

КХЛ, Евролига и российские волейбольные лиги в ESPN отсутствуют — появятся с платным источником.

## Как получить APK без Android Studio (через GitHub, бесплатно)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository → любое имя → Create).
2. На странице репозитория: **Add file → Upload files**, перетащите **всё содержимое** папки `SportPrognoz`
   (с компьютера — перетаскиванием папок). Нажмите **Commit changes**.
3. Проверьте, что загрузилась папка `.github/workflows/build.yml` (скрытые папки иногда не перетаскиваются).
   Если её нет: **Add file → Create new file**, в имени напишите `.github/workflows/build.yml`
   и вставьте содержимое файла из архива.
4. Откройте вкладку **Actions** → «Сборка APK». Сборка запустится сама (или нажмите **Run workflow**), идёт ~5 минут.
5. Когда появится зелёная галочка, откройте запуск и скачайте внизу **SportPrognoz-apk** (zip с APK внутри).
6. Перекиньте APK на телефон и установите (разрешите «установку из неизвестных источников»).

## Как собрать в Android Studio

Откройте папку `SportPrognoz` → дождитесь синхронизации Gradle → Build → Build APK(s).

## Структура

```
app/src/main/java/com/sportprognoz/app/
  data/     источник данных (EspnApi), лиги, модели
  predict/  математика (PMath) и прогнозы (Predictor)
  ui/       экраны на Jetpack Compose
```

Чтобы подключить платный API, добавьте новый класс в `data/` с теми же методами
(`matches`, `standings`, `extras`) — модели прогнозов менять не нужно.

Прогнозы — вероятностная оценка, а не гарантия результата.
